## RETURNS & REFUNDS

### Return Request - Within Policy
```
Hi [Name],

No problem at all - I'm happy to help with your return.

Here's how it works:
1. Reply to this email with your reason for returning (helps us improve!)
2. I'll send you a prepaid return label
3. Ship it back within 14 days
4. We'll process your refund within 3-5 business days of receiving it

[Or if exchange: Would you like to exchange for a different product instead? Same process, we just ship the new one as soon as we receive the return.]

Let me know and I'll get that label sent over!
```

### Return Request - Outside Policy
```
Hi [Name],

Thanks for reaching out about returning your order.

I checked and it looks like your order is outside our standard 30-day return window (purchased on [DATE]).

That said, I want to see if we can help. Can you tell me more about why you'd like to return it? 

[If defect/quality issue: If there's a product issue, we'll absolutely make it right regardless of timing.]

[If buyer's remorse: Depending on the situation, we may still be able to accommodate a return or exchange.]

Let me know what's going on and I'll see what I can do.
```
