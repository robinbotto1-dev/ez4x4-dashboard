# EZ4X4 Product Description Templates

*Optimized templates for Shopify product pages*

## TEMPLATE STRUCTURE

Every product description should include:

1. **Hook** - Attention-grabbing first line
2. **Problem** - What pain point does this solve?
3. **Solution** - How does this product solve it?
4. **Key Features** - Bullet points of benefits
5. **Specs** - Technical details
6. **What's Included** - Box contents
7. **Compatibility** - Vehicle fitment
8. **Trust Signals** - Warranty, reviews, etc.

## SEO OPTIMIZATION CHECKLIST

For each product page:

### Title Tag (60 characters max)
Format: `[Product Name] for [Vehicle] | EZ4X4`
Example: `Freedom Panel Carrier for Ford Bronco | EZ4X4`

### Meta Description (155 characters max)
Format: `[Benefit statement]. [Feature highlight]. [Trust signal]. Shop now.`
Example: `Scratch-free freedom panel storage for Ford Bronco 2-door and 4-door. Padded interior, wall mount or floor stand. Lifetime warranty. Free shipping $150+.`

### H1 (One per page)
Should match or closely match product name.

### Image Alt Text
Format: `[Product Name] for [Vehicle] - [View/Feature]`
Example: `Freedom Panel Carrier for Ford Bronco - Front View`

### URL Slug
Format: `/products/[product-name-vehicle]`
Example: `/products/freedom-panel-carrier-bronco`

## WRITING GUIDELINES

### Voice
- Confident but not arrogant
- Helpful, not salesy
- Technical when needed, accessible always
- Second person ("you" not "the customer")

### Formatting
- Short paragraphs (2-3 sentences max)
- Bullet points for features
- Bold for emphasis (sparingly)
- Emoji icons for visual breaks ✓

### Words to Use
- Upgrade, transform, unlock
- Designed for, built for
- Premium, quality, durable
- Simple, easy, quick
- Trusted, proven, tested

### Words to Avoid
- Best, greatest, perfect (subjective claims)
- Revolutionary, game-changer (overused)
- Cheap (say "affordable" or "value")
- Just, only, simply (weak)
