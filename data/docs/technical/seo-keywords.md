## Technical SEO Checklist

### Product Pages
- [ ] Include primary keyword in title tag
- [ ] Include primary keyword in H1
- [ ] Include keyword in first 100 words
- [ ] Add schema markup (Product, Review)
- [ ] Optimize image alt text with keywords
- [ ] Include keyword in URL slug
- [ ] Add FAQ section with question keywords

### Blog Posts
- [ ] Target one primary keyword per post
- [ ] Include related keywords naturally
- [ ] Use keyword in title, H1, and H2s
- [ ] Internal link to product pages
- [ ] Add table of contents for long posts
- [ ] Include images with alt text
- [ ] Aim for 1,500+ words

### Site-Wide
- [ ] Submit sitemap to Google Search Console
- [ ] Ensure mobile-friendly design
- [ ] Optimize page load speed
- [ ] Fix broken links
- [ ] Add breadcrumb navigation
- [ ] Create logical URL structure
